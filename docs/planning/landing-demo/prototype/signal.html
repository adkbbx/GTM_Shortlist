    Watch the work, not a spinner.

    Two ways to run it

    Open source core. Hosted if you want it.

    The research engine is open source. Run it with your own keys, or use the hosted version and keep your research in an account.

    Run it yourself

    • MIT-licensed web app, API and worker
    • Your own search and model keys
    • Research stays in your own database
    Read the setup guide →

    Use the hosted version

    • An account that keeps your saved research
    • Research credits instead of provider keys
    • An optional call to talk through your shortlist
